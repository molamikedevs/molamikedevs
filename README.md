## 🚀 Featured Projects

### 📚 [Dersly](https://dersly.pro)

A learning platform I built for my own English students and use with them. Students sign in to access their homework and materials, and take a placement test that sets their level. Teachers manage students, groups and assignments from one place.
**Stack:** `Next.js` `TypeScript` `Supabase` `Tailwind CSS` `shadcn/ui` `Vercel`
🔗 [Live](https://dersly.pro) · [Code](https://github.com/molamikedevs/dersly)

### 🏢 [Estatly](https://estatly-three.vercel.app)

An internal property management platform for real estate agencies. Includes role-based permissions, a property approval workflow, server-side filtering, sorting and pagination, optimistic updates, and a dashboard powered by Postgres functions.
**Stack:** `React` `TypeScript` `Vite` `Supabase` `TanStack Query` `Tailwind CSS` `shadcn/ui`
🔗 [Live](https://estatly-three.vercel.app) · [Code](https://github.com/molamikedevs/estatly)

### 🎬 [TinyMoviez Dashboard](https://tiny-moviez-five.vercel.app)

A movie dashboard built from scratch with a custom Vanilla JavaScript MVC architecture. Features custom pagination, bookmarking, recent search history, and multi-level filtering and sorting, all through direct DOM manipulation.
**Stack:** `Vanilla JavaScript` `OOP` `MVC Architecture` `TMDB API`
🔗 [Live](https://tiny-moviez-five.vercel.app) · [Code](https://github.com/molamikedevs/tiny-moviez)
